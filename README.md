# Lembra Tudo

App que avisa antes de vencer assinaturas, documentos, garantias e contas. Funciona offline, sem cadastro, e pode ser instalado no celular (PWA).

- `index.html`: o app inteiro (interface e lógica)
- `sw.js`: funcionamento offline e avisos
- `manifest.webmanifest`: dados para instalar na tela inicial

Publicado com GitHub Pages a partir da branch `main`.
